# Prozessor mit Hazard Unit

Programm:

```s
.globl main
.data
  nums: .word 30
.text
main:
  addi t1, zero, 12
  la   t0, nums
  lw   t0, 0(t0)
  sub  t2, t0, t1
  blt  t1, t2, end
  and  t2, t2, t1
end:
  add  t2, t2, t1
  addi t3, zero, 10
```

Pipeline:

| PC | fetch            | decode           | execute          | memory           | writeback        |
| -- | ---------------- | ---------------- | ---------------- | ---------------- | ---------------- |
| 0  | addi x6, x0, 12  |                  |                  |                  |                  |
| 4  | addi x5, x0, 0   | addi x6, x0, 12  |                  |                  |                  |
| 8  | lw x5, 0(x5)     | addi x5, x0, 0   | addi x6, x0, 12  |                  |                  |
| C  | sub x7, x5, x6   | lw x5, 0(x5)     | addi x5, x0, 0   | addi x6, x0, 12  |                  |
| 10 | blt x6, x7, .+8  | sub x7, x5, x6   | lw x5, 0(x5)     | addi x5, x0, 0   | addi x6, x0, 12  |
| 10 | blt x6, x7, .+8  | sub x7, x5, x6   |                  | lw x5, 0(x5)     | addi x5, x0, 0   |
| 14 | and x7, x7, x6   | blt x6, x7, .+8  | sub x7, x5, x6   |                  | lw x5, 0(x5)     |
| 18 | add x7, x7, x6   | and x7, x7, x6   | blt x6, x7, .+8  | sub x7, x5, x6   |                  |
| 18 | add x7, x7, x6   |                  |                  | blt x6, x7, .+8  | sub x7, x5, x6   |
| 1C | addi x28, x0, 10 | add x7, x7, x6   |                  |                  | blt x6, x7, .+8  |
| 20 |                  | addi x28, x0, 10 | add x7, x7, x6   |                  |                  |
| 24 |                  |                  | addi x28, x0, 10 | add x7, x7, x6   |                  |
| 28 |                  |                  |                  | addi x28, x0, 10 | add x7, x7, x6   |
| 2C |                  |                  |                  |                  | addi x28, x0, 10 |
| 30 |                  |                  |                  |                  |                  |

## a) Stall

Stall bei `PC = 10` wegen Data-Hazard: `lw` lädt ins register `t0` welches aber unmittelbar von `sub` benötigt wird. Der wert in `t0` ist erst am ende des memory zyklus für `sub` verfügbar, durch einen stall wird `sub` erst ausgeführt, wenn der wert im register vorhanden ist.

## b) Flush

Flush bei `PC = 18` wegen Control-Hazard: Bei der Ausführung von `blt` wird festgestellt dass gebrancht werden muss. Der folge befehl `and` ist jedoch schon geladen, und wird geflusht.

## c) Forward

1. Forward bei `PC = 18` wegen Data-Hazard: `blt` benötigt ergebnis von `sub`. `sub` ergebnis wird geforwarded
2. Forward bei `PC = 24` wegen Data-Hazard: `add` benötigt ergebnis von `addi`. `addi` ergebnis wird geforwarded
